# Стенд автоматического теста бесперебойников (ИБП)

Программа управляет лабораторным стендом: задаёт напряжение с блока питания, коммутирует контакты через STM32 и снимает измерения с мультиметра / термометра.

## Назначение

ИБП подключается к специальной электросхеме. Микроконтроллер **STM32** переключает контакты (реле), имитируя сценарии работы сети. Блок питания **ODP3032** задаёт уровни напряжения, мультиметр **TH1951** контролирует измерения. Опционально **AT4508** ведёт термомониторинг при длительных прогонах.

## Состав железа

| Устройство | Роль | Скорость COM |
|---|---|---|
| TH1951 | Мультиметр (SCPI) | 9600 |
| ODP3032 | Программируемый БП | 115200 |
| STM32 | Коммутация контактов схемы | 9600 |
| AT4508 | Термометр (опционально) | 9600 |

## Структура репозитория

```
main.py                 # запуск GUI
requirements.txt
stand/
  config.py             # порты, профили теста, допуски
  tester.py             # логика теста ИБП и термомониторинга
  app/                  # Tkinter-интерфейс
  devices/
    base.py             # общий SerialDevice
    multimeter.py       # TH1951
    power_unit.py       # ODP3032
    stm32.py            # коммутатор контактов
    thermometer.py      # AT4508
results/                # сюда пишутся CSV (в git не попадает)
```

## Установка

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Нужен Python 3.10+ и Tkinter (обычно входит в поставку Python; в Linux: `sudo apt install python3-tk`).

## Запуск

```bash
python main.py
```

1. Подключите приборы по USB/COM.
2. Нажмите **Обновить порты** и назначьте порт каждому устройству.
3. **Проверить связь** — индикаторы станут зелёными при успехе.
4. **Старт теста ИБП** — прогон профиля напряжений с коммутацией контактов.
5. Либо **термомониторинг**: разовый снимок или запись по времени в `results/`.

## Профиль теста ИБП

Задаётся в `stand/config.py` (`DEFAULT_UPS_PROFILE`):

```python
# (напряжение_БП, команда_пинов_STM32, ожидаемое_напряжение)
(7, "2", 7.0),
(10, "2", 10.0),
...
```

Команды пинов (`00000`, `11111`, `2`, …) интерпретирует прошивка STM32 на схеме коммутации.

## История и что было не так

Раньше код лежал плоским набором скриптов (`Connection_*.py`, `test_PowerUnit.py`, черновик `test.py`), GUI падал при числе COM-портов меньше числа устройств, порты иногда путались местами, ресурсы serial закрывались через `__del__()`. Сейчас драйверы собраны в пакет, порты выбираются безопасно, устройства закрываются через context manager.

## Лицензия / заметки

Лабораторный внутренний стенд. Под конкретную прошивку STM32 и модель ИБП профиль в `config.py` нужно подстроить под вашу схему.
